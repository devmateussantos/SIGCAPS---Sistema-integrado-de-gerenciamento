# ADR-002 — Modelagem de Atividades em Grupo 

## Status: Aceita. 

### Contexto 

Inicialmente o sistema possuía a entidade AcolhimentoGrupo. 

Durante a análise da rotina do CAPS, identificou-se que diferentes profissionais podem realizar diversas modalidades de atividades coletivas, não apenas acolhimentos. 

### Alternativas avaliadas 

 1. Manter uma entidade específica para acolhimento.  

 2. Generalizar para uma entidade de atividades em grupo.  

### Decisão 

Adotar a entidade AtividadeGrupo, com um tipo configurável (TipoAtividadeGrupo). 

Os participantes serão armazenados por uma entidade de associação, invisível para o usuário. 

### Consequências 

 - O sistema fica mais flexível.  

 - Novas modalidades podem ser adicionadas sem alterar a estrutura.  

 - A interface reflete melhor a forma como os profissionais trabalham.  

 - O cálculo da produção continua simples: uma atividade em grupo registrada equivale a uma produção, independentemente do número de participantes.
