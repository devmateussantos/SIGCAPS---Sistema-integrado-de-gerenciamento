# ADR-005

## Separação entre Perfil e Permissões

Status

Aceita

## Contexto

Durante a modelagem da entidade Usuário foi identificado que uma função profissional não representa necessariamente todas as permissões do sistema.

Como exemplo, Técnicas de Enfermagem podem realizar agendamentos quando necessário, embora essa atividade seja normalmente executada pela Recepção.

## Decisão

Manter uma entidade Perfil representando a função do usuário.

Documentar as permissões através de uma Matriz de Permissões.

No MVP as permissões serão implementadas na aplicação utilizando o Perfil como referência.

## Consequências

O domínio permanece simples.

A arquitetura fica preparada para futura evolução para RBAC completo.
