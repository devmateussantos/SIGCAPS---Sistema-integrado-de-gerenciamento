
# ADR-001 — Monorepo 

## Status: Aceita.

### Contexto 

O projeto possui frontend, backend, banco de dados e documentação. 

Precisávamos decidir entre utilizar múltiplos repositórios ou um monorepo. 

### Decisão 

Adotar uma arquitetura baseada em Monorepo. 

### Justificativa 

 - Centraliza toda a documentação.  

 - Facilita o versionamento.  

 - Simplifica a configuração do ambiente.  

 - Favorece o compartilhamento de código.  

 - Aproxima o projeto de práticas utilizadas por empresas.  

### Consequências 

 - Estrutura mais organizada.  

 - Um único fluxo de versionamento.  

 - Menor complexidade para novos colaboradores.
