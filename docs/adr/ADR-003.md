# ADR-003 — Endereço incorporado à entidade Paciente 

## Status: Aceita.

### Contexto 

Foi avaliada a criação de uma entidade independente para armazenar endereços. 

### Alternativas 

 - Criar entidade Endereco.  

 - Manter os campos diretamente em Paciente.  

### Decisão 

Para o MVP, os campos de endereço permanecerão na entidade Paciente. 

### Justificativa 

 - Reduz a complexidade inicial.  

 - Atende às necessidades atuais da unidade.  

 - Evita relacionamentos desnecessários no início do projeto.  

### Consequências 

Caso o sistema evolua para múltiplos endereços ou reutilização por outras entidades, será criada a entidade Endereco em uma versão futura.
