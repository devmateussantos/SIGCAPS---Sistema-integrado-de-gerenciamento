# ADR-004

## Padronização da Entidade Paciente

Status

Aceita

## Contexto

Durante a modelagem do domínio foi necessário definir uma estrutura consistente para a entidade Paciente.

## Decisão

Foram adotadas as seguintes decisões:

- UUID como chave primária.
- TIMESTAMPTZ para datas de auditoria.
- CPF armazenado sem máscara.
- CEP armazenado sem máscara.
- Nome Social opcional.
- Sexo armazenado como ENUM.
- Pacientes nunca serão excluídos.
- Histórico preservado por inativação.

## Consequências

A entidade passa a servir como referência para a modelagem das demais entidades do sistema.
