# Release v0.5.0 — Atendimento e Triagem

**Data:** 2026-08-08  
**Status:** Concluída.

## Adicionado
- Modelo de Domínio e Dicionário de Dados de Atendimento v1.0.
- Modelo de Domínio e Dicionário de Dados de Triagem v1.0.
- ADR-007 — Atendimento originado de Agendamento.
- ADR-008 — Triagem independente das aferições.
- Regras RN-034 a RN-054.

## Alterado
- Agendamento → Atendimento consolidado como 1:0..1.
- Atendimento passou a registrar `dataHoraAtendimento`.
- Triagem passou a registrar `dataHoraAfericao`.
- Padronização de autoria com `criadoPorUsuarioId` e `alteradoPorUsuarioId`.

## Evolução futura
- Acompanhamento diário de pacientes intensivos.
- Histórico de alterações e remarcações de Agendamento.
- Origem do Agendamento.
