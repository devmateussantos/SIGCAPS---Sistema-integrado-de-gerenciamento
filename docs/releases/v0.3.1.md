# Release v0.3.1 — Sprint de Organização

## Objetivo

Padronizar a documentação do SIGCAPS antes do início da modelagem das entidades de negócio restantes.

## Entregas

- Reorganização da estrutura documental.
- Correção da numeração das ADRs.
- Criação do Modelo de Domínio de Usuário.
- Criação do Dicionário de Dados de Usuário.
- Criação do Modelo de Domínio de Perfil.
- Criação do Dicionário de Dados de Perfil.
- Criação da Matriz de Permissões.
- Atualização do CHANGELOG.
- Atualização do ROADMAP.

## Resultado

A documentação do projeto passa a seguir um padrão único e escalável para todas as próximas versões.
